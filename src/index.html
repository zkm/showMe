ShowMe JavaScript Logic

Date Windows Rendered by Live JavaScript Checks

A lightweight script scans each .hide block, parses its data-start and data-end range, and decides in real time whether it should render.

The behavior is driven from src/js/script.js, so content scheduling stays declarative in HTML while logic remains centralized and testable.

Execution Flow

What Happens on Page Load

  1. Wait for DOMContentLoaded.
  2. Find all elements with class .hide.
  3. Read data-start/data-end.
  4. Toggle style.display based on today.

Rule: if now >= start && now <= end show the block, otherwise hide it.
